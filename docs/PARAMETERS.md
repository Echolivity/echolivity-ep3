## Controller bank "Dub" (bank 1, Push / controller)

1. Echo Sustain · 2. Echo Volume · 3. Echo Delay · 4. Repeat LP · 5. Repeat HP · 6. HOLD Latch · 7. DRIVE Latch · 8. STOP Latch

HOLD / DRIVE / STOP in the bank are the Latch parameters (a controller encoder or toggle shows their state). The Momentary parameters remain for mapping hardware buttons that send on/off (press = on, release = off). Live behaviour: UNVERIFIED.
